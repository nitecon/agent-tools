# T012 - User documentation

Publish the supported knowledge graph and OKF workflows after conformance closes.

## Requirements

- Document `.agents/knowledge/`, explicit bundles, validation, indexing, search,
  graph traversal, export, publish dry runs, and additional upstream gateways.
- Explain canonical identity, authority, rebuildable state, lifecycle/trust
  labels, unresolved links, diagnostics, migration, rebuild, and recovery.
- Use tested CLI examples and link detailed contracts rather than duplicating them.
- State that two-way gateway synchronization and Attested Computation execution
  are deferred and unsupported.

## Validation

Documentation commands execute successfully against the checked-in example
fixture, and CLI help/README links resolve to the detailed documentation.
